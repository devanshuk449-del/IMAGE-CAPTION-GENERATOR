# Image Caption Generator

## Overview
This project generates captions for images using Deep Learning and Computer Vision techniques.

## Features
- Automatic image caption generation
- Deep learning model
- Image preprocessing
- Caption prediction

## Technologies Used
- Python
- TensorFlow/Keras
- Jupyter Notebook
- NumPy
- Pandas

## How to Run
1. Install requirements
2. Open the notebook
3. Run all cells
