# Image Caption Generator

## Overview

This project generates descriptive captions for images using Deep Learning techniques. It combines Computer Vision and Natural Language Processing to automatically understand image content and generate human-readable captions.

## Features

* Automatic image caption generation
* Deep Learning-based architecture
* Image feature extraction using CNN
* Caption generation using LSTM
* Supports custom image inputs

## Tech Stack

* Python
* TensorFlow / Keras
* NumPy
* Pandas
* Matplotlib
* Jupyter Notebook

## Dataset

Flickr8K Dataset

## Workflow

1. Image preprocessing
2. Feature extraction using CNN
3. Caption sequence generation
4. Caption prediction using LSTM
5. Output generation

## Results

The model successfully generates meaningful captions for unseen images.

## Future Improvements

* Use Transformers instead of LSTM
* Improve caption quality
* Deploy as a web application
